Fill a template in the browser

This page runs docvane in your browser. The template is read with File.arrayBuffer(), the result is made on this computer, and nothing is uploaded: the page loads no code or data from other sites (its Content-Security-Policy allows only this site).

Tags start with and end with (for templates written with other delimiters, such as {{name}} or [[name]])

Data

JSON for the template. For a new template the fields come from its schema; images must be data URLs (data:image/png;base64,…).

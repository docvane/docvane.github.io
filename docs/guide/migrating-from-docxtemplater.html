#Migrating from docxtemplater

tplvane reads the basic tags of docxtemplater: values, loops, inverted sections, conditions, {.}, {/} and changes of delimiters. Most templates that use only these tags work without changes. This guide lists what works as it is, what needs a change, and what tplvane does not have. It is based on the public documentation of the open-source core of docxtemplater; the syntax of its paid modules is named only to say what to use instead.

#Code

// docxtemplater: a zip object in, rendered in place
const doc = new Docxtemplater(zip, { paragraphLoop: true, linebreaks: true });
doc.render(data);

// tplvane: the bytes of the template in, the bytes of the result out
import { render } from 'tplvane';
const result = render(templateBytes, data);

tplvane needs no ZIP library: it takes the file as a Uint8Array (a Node.js Buffer is one) and returns a new one. inspect(templateBytes) lists the tags and returns a JSON Schema of the data; validate(templateBytes, data) checks data without rendering.

#Works without changes

docxtemplatertplvane
{name}The same. Only own data properties are read; names such as __proto__ and constructor are refused.
{user.name} with the angular parser (docxtemplater/expressions.js)The same, without a parser: a dot reads a field of an object. docxtemplater's default parser reads a key named user.name instead; data written for it needs nested objects.
{#users}…{/users}The same: a loop over a list, shown once for an object (with the object as the current item) or another true value. What it repeats follows from where its tags are: part of a paragraph, whole paragraphs, table rows.
{^users}…{/users}The same: shown when the value is missing, false or an empty list.
{.}The same: the current item of a list of plain values.
{/}The same: closes the innermost open section.
{=[[ ]]=}The same syntax. In tplvane the change holds for the rest of the part (the body, a header, a slide, a sheet).
Option delimiters: { start: '[[', end: ']]' }The same option, in inspect, render, validate and --delimiters "[[ ]]" on the command line.
PowerPoint templates (.pptx)The same tags; also in notes, and a section whose tags each fill a shape of their own repeats slides.

#Needs a change

docxtemplatertplvane
paragraphLoop: trueNo option needed: a section whose opening and closing tags are each alone in a paragraph (spaces aside) repeats the paragraphs between them, and the two paragraphs with the tags are left out. A section that spans paragraphs needs each of its tags alone in its paragraph: split {#repo} {name} in one paragraph and {/repo} in another, or two tags in one paragraph ({#a}{#b}), into one tag per paragraph. tplvane reports such a template with TV_E_SECTION_PLACEMENT. Templates made for the default paragraphLoop: false lose the empty paragraphs around such loops.
linebreaks: trueNo option needed: a line break in a value always becomes a line break in the document. Without the option, docxtemplater ignores line breaks in values, so data that relied on that now shows them.
Expressions of the angular parser, such as {price * 1.2}, {users[0].name} or {a ? b : c}tplvane has its own expression language, without any code from the template: ==, !=, <, <=, >, >=, &&, ||, ! and parentheses, on names, numbers, texts, true, false and null. == is strict, so {#count == "1"} is false for the number 1. The length of a list is read as a field, so {#users.length > 3} works as it is. Arithmetic, indexing, the conditional operator, function calls and assignments are not available: compute such values in the data.
Filters of the angular parser, such as {price | currency} or {users | olderThan:15}A fixed list of formatters: upper, lower, capitalize, trim, default, number, percent, currency, date and link. Arguments are literals in parentheses, not after a colon: {price | currency("EUR")}.
nullGetterBy default docxtemplater writes the text undefined for a missing or null value. tplvane has the option missing: 'error' (default) reports every missing value with its place and the path of the field; 'empty' shows nothing. In tplvane a null value shows nothing with either setting. Inside a loop, docxtemplater looks for a null value in the outer data too; tplvane does so only for a field that is absent.
An image tag {%image} or {%%image} of a paid module{%image} is part of tplvane: the value is the bytes of a PNG, JPEG or GIF, a data URL, or { data, width, height, alt }. Addresses are fetched only through renderAsync with a fetchImage function you pass.
A tag {~html} or {~~html} of a paid module{~name} in tplvane is Markdown, not HTML: headings, lists, bold, italic, code and links, in the template's own styles.
Excel templates of a paid moduleExcel templates are part of tplvane: the same tags in cells, typed values, repeated rows with their formulas, and totals that follow the copies.
Repeating slides with {:users} of a paid module{#users} and {/users}, each alone in a shape, repeat the slides from the one with the opening tag to the one with the closing tag.

#Not available

docxtemplaterWhy, and what to do
{@rawXml}Data cannot insert raw XML: tplvane escapes every value, so that data cannot change the structure of a document. Use Markdown ({~name}) for formatted text.
{-w:p loop} and other element namesLoops over a named element are not available. Put the tags of {#loop} alone in their paragraphs, or in the cells of a table row.
Functions in the data (lambdas)Not available: tplvane never calls data. Compute the values before rendering.
Promises in the data with renderAsyncNot available: resolve them before rendering. tplvane's renderAsync exists only to fetch images.
Other tags of paid modules ({:…}, {$chart}, {r@…}, {?…}, {>…})Not available.
syntax options (allowUnopenedTag, allowUnclosedTag, changeDelimiterPrefix)tplvane reports every unopened, unclosed or crossed tag with its place and a hint; it does not render a template with such problems. A tag between equals signs always changes the delimiters.
parser, modules, errorLoggingNot available. Problems are thrown as a TvError with a code, a place in the template and a hint, all of them at once; warnings go to the onWarning option.

#Errors

docxtemplater and tplvane both report template errors, but the format differs. tplvane throws TV_E_TEMPLATE_INVALID for the template and TV_E_DATA_INVALID for the data, each listing every problem in errors with a code, a place (body, table 1 row 2 cell 1, paragraph 1) and a hint; see the error catalogue.
